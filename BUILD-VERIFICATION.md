# Controles voor versie 0.2.1

Deze versie is vóór publicatie gecontroleerd.

- De code is gebouwd voor Chrome en andere Chromium-browsers.
- De 148 automatische tests zijn geslaagd.
- De 16 browsertests met voorbeeldgegevens zijn geslaagd. Die controleren onder andere reset, nieuwe cijfers en een ster die later een cijfer wordt.
- Er zijn geen wachtwoorden of toegangssleutels in de gepubliceerde code gevonden.
- De installatie-ZIP bevat alleen de bestanden die de extensie nodig heeft.
- De ZIP is hetzelfde bestand als het bestand bij de GitHub-release.

De tests gebruiken voorbeeldgegevens. Ze bewijzen niet dat CijferReveal op elke school werkt. Zie de [README](README.md) voor de grenzen en hulp bij problemen.
